# Falling Ball Euler Method

A small Python project I made over the summer to practise coding and explore mechanics.

I experimented with:
- Falling objects using Euler's method
- Projectile motion
- A bouncing ball with simple collision behaviour
- Pendulum motion

**Tools:** Python, NumPy, Matplotlib

The simulations use time steps to update velocity and position, with plots to visualise the motion.

## Run it

```bash
pip install jupyter numpy matplotlib
jupyter notebook falling-ball.ipynb
```
